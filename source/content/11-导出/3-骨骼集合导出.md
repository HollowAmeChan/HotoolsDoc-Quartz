# 骨骼集合导出

活动对象必须是骨架，并且至少存在一个 Bone Collection。可以单独执行，也可以随 HoTools FBX 一起输出。

JSON 会记录：

- 格式版本和导出时间。
- 骨架名称。
- 每个集合的名称。
- 父集合名称；顶层集合为空字符串。
- 该集合直接持有的骨骼名称。

“直接持有”不包含子集合中的骨骼，这是为了保留 Blender 原本的层级关系。Unity 端如果需要递归成员，应在导入后根据 `parent` 自己展开。

> 同一根骨可以属于多个集合，因此导出的骨骼引用总数不一定等于骨架骨骼数量。

对应 Unity 端说明见 [[../14-Unity/1-骨骼数据导入|骨骼数据导入]]。
