# 骨骼约束导出

入口在 `文件 > 导出 > HoTools - 骨骼约束 (.json)`，也可以在 HoTools FBX 导出中勾选附加 JSON。

活动对象必须是骨架。当前导出器主要识别 HoTools 的 Fan/Twist 辅助骨语义，并只保留约束到同一骨架内部骨骼的关系；跨骨架、物体目标和无法映射的约束不会进入结果。

## 使用方式

1. 让目标骨架成为活动对象。
2. 确认辅助骨约束在 Blender 中工作正常。
3. 导出 JSON，或者随 FBX 一起导出。
4. 在 Unity 中对同一套骨骼层级导入。

随 FBX 导出并启用 MCH 时，约束目标会跟随 MCH 映射，JSON 中的目标路径因此也会指向导出后的实际骨骼。

> JSON 和 FBX 必须来自同一次、同一组选中对象的导出。骨骼改名或重新生成 MCH 后继续使用旧 JSON，路径一定可能失配。

对应 Unity 端说明见 [[../14-Unity/1-骨骼数据导入|骨骼数据导入]]。
