# 属性动画导入

把 `.anim` 放入 Unity 项目后，先在 Animation 窗口检查，不要直接接入正式 Animator。

## 检查顺序

1. 确认 Clip 的帧率、时长和 Loop Time。
2. 展开曲线，检查每条绑定的层级路径和组件类型。
3. 把 Clip 临时播放到与导出时同结构的 Prefab 上。
4. 确认布尔开关没有被连续插值，普通浮点曲线的切线也符合预期。

目前导出器明确映射的 `mmd_root.show_meshes` 会绑定到 GameObject 的 `m_IsActive`。其他未知 Blender 属性使用占位属性名，通常需要在 Unity 端根据实际组件重新绑定。

## 常见问题

- 完全没有效果：层级路径没有命中，或绑定到了错误的 Prefab 根。
- 只有部分曲线有效：已知映射能命中，未知属性仍是占位绑定。
- 时间整体偏移：检查导出时是否开启“对齐到起始帧”。
- 开关中间出现小数：该轨道没有被识别为布尔值，需要修正映射或 Unity 曲线切线。
