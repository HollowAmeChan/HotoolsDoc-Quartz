# 骨骼数据导入

这部分必须配合 HoTools 导出的 JSON 使用，不能拿任意 Blender 约束文件直接导入。

## 骨骼约束

约束 JSON 记录的是导出时识别出的 Fan/Twist 辅助骨关系，目标只允许是同一骨架中的其他骨。导入时应让 JSON 对应到同一次导出的 FBX 或 Prefab 层级。

如果 Unity 提示找不到骨骼，依次检查：

- FBX 和 JSON 是否来自同一次导出。
- Unity 中是否改过骨骼名称或层级。
- Blender 导出时是否启用了 MCH，Unity 当前模型是否也包含这些 `MCH_` 骨。
- Prefab 根节点是否和导入器使用的根一致。

## 骨骼集合

集合 JSON 保存名称、父集合和直接成员骨骼。它用于在 Unity 侧重建分组或作为工具数据，不会改变蒙皮权重。

一根骨可以出现在多个集合中；子集合成员也不会自动并入父集合。导入端需要保留这种多对多和层级关系，不能简单把集合当成互斥分组。

导出端说明见 [[../11-导出/2-骨骼约束导出|骨骼约束导出]] 与 [[../11-导出/3-骨骼集合导出|骨骼集合导出]]。
