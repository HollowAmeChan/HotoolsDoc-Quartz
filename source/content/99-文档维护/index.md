# 文档维护

此目录面向文档维护者，不是插件功能说明。

- [[写作与命名规范]]：目录、文件、标题、链接和截图的统一规则。
- [[功能页模板]]：新增或补写功能时使用的固定大纲。
- [[截图清单]]：按模块追踪人工截图进度。
- [[功能覆盖矩阵]]：插件源码模块与文档页面的对应关系。

## 更新流程

1. 对照插件注册入口和 `bl_label` 更新覆盖矩阵。
2. 更新或新增对应功能小节。
3. 在 Blender 中验证前置条件、参数和实际结果。
4. 按截图清单补图，完成后再把图片引用写入功能页。
5. 运行链接、孤立资源和 Quartz 构建检查。
