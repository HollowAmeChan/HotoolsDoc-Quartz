# 顶点组与权重

入口主要位于对象数据属性的顶点组扩展，以及编辑模式相关菜单。大多数操作只影响所选顶点；涉及骨架的功能还依赖正确的 Armature 修改器和骨骼命名。

## 页面

- [[复制编辑与选择]]：复制粘贴、增减、选择、规格化和从组移除。
- [[镜像与对称]]：组内翻转、同步到对称骨骼、生成镜像权重组。
- [[清理与限制]]：垃圾权重、空组、非骨骼组、最大影响数与未加权点。
- [[平滑锐化与调试]]：柔化、锐化、膨胀/侵蚀、扩散和权重 Debug。
