# 贴图图集

“打包主色与法线贴图”会扫描所选网格实际使用的材质，生成规则网格图集，同时修改活动 UV 和材质引用以对应新的区域。

## 材质要求

- 材质必须启用节点，并且有活动的 Material Output。
- 连接到输出的原理化 BSDF 必须有且只有一个。
- Base Color 必须能追溯到一张图像纹理。
- Normal 最多追溯到一张图像纹理，没有法线贴图也可以打包。
- 所有参与物体都必须有活动 UV，面不能引用空材质槽。

工具会在执行前弹出扫描结果，列出贴图通道、尺寸、色彩空间、来源、使用材质，以及每个对象的活动 UV 和面数。这里有异常就先取消，不要直接确认。

## 输出与场景修改

图集按材质数量排成方形网格，输出主色 PNG；存在法线时会额外输出 Non-Color 法线图集。输出目录、图集名称和是否覆盖同名文件都在面板中设置。

执行后会：

- 生成图集图像文件。
- 变换所选物体的活动 UV 到各自格子。
- 复制材质并把主色/法线节点改为图集。
- 让相同原材质继续共用同一份图集材质副本。

==这不是只写文件的无损操作，UV 和材质引用都会改变。== 建议在副本文件里打包，确认效果后再合回正式工程。
