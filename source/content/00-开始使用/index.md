# 开始使用

## 阅读顺序

1. [[安装与更新]]：根据 Blender 和 Python 版本选择正确安装包。
2. [[偏好设置与入口]]：启用可选模块、注册内置资源库并找到各类工具。
3. 回到 [[../index|功能目录]]，按任务进入对应模块。

## 当前兼容范围

| Blender | Python | 安装包标识 |
| --- | --- | --- |
| 4.5 | 3.11 | `Blender-4.5-py311` |
| 5.2 | 3.13 | `Blender-5.2-py313` |

普通用户不需要自行编译 native 后端。安装包已经包含对应 Python 版本的依赖，两个版本的依赖不能混用。
