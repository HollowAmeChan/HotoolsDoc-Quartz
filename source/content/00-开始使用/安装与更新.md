# 安装与更新

## 通过安装包安装

1. 从 Release 页面下载与 Blender 版本对应的 `HoTools-*.zip`。不要优先使用 GitHub 自动生成的 `Source code` 压缩包。
2. 在 Blender 中打开 `编辑 > 偏好设置 > 插件`。
3. 选择“从磁盘安装”，选中下载的 zip。
4. 启用 `HoTools`。

## 手动安装

将插件目录放到 Blender 的 `scripts/addons` 下，最终目录名必须是 `HoTools`，并确认其下直接存在 `__init__.py`。源代码仓库不一定包含 Release 包预编译好的全部依赖，只建议开发者使用这种方式。

## 更新与回退

更新前保存当前 `.blend` 文件并退出 Blender。移除旧版后安装新 zip，再检查偏好设置中的 OmniNode、exIcon 和内置资源库状态。遇到严重回归时，安装上一个已知可用的 Release 包。

## 常见问题

### 插件无法启用

核对 Blender、Python 与安装包标识是否一致，并检查是否误装了 GitHub 自动生成的源码包。

### Blender 找不到插件

检查是否出现 `HoTools-x.y/HoTools/__init__.py` 这样的双层目录，以及最内层目录名是否为 `HoTools`。
