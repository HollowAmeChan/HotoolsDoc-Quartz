# 偏好设置与入口

## 插件偏好设置

- `注册内置资源库`：把插件内的 `HoAssets` 注册到 Blender 资产库。
- `exIcon`：启用视图中的快捷图标叠加，并设置大小和不透明度。
- `OmniNode`：注册节点编辑器与节点类型。首次阅读请转到 [[../20-OmniNode/启用与界面|启用 OmniNode]]。
- 快捷键区域：可修改填充选择、加选/减选 Ring 和鼠标位置切换顶点组等默认键位。

## 常见入口

| 入口 | 主要内容 |
| --- | --- |
| 3D 视图 `N > HoTools` | 顶点色、形态键、骨骼、动画、检查等主要面板 |
| 右键与编辑菜单 | 建模、骨骼、UV 和快捷操作 |
| 对象数据属性 | 顶点组与形态键扩展 |
| 对象、网格、骨骼属性 | HoTools 物理与碰撞属性 |
| 节点编辑器 | OmniNode 自动化和物理节点图 |
| 插件偏好设置 | 可选模块、内置资产与快捷键 |
