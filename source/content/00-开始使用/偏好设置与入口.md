
# 偏好设置

![[Pasted image 20260729153547.png]]

- `注册内置资源库`：把插件内的 `HoAssets` 注册到 Blender 资产库。
- `exIcon`：启用视图中的快捷图标叠加，并设置大小和不透明度。
- `OmniNode`：注册节点编辑器与节点类型。首次阅读请转到 [[../20-OmniNode/1-启用与界面|启用 OmniNode]]。
- 快捷键区域：可修改填充选择、加选/减选 Ring 和鼠标位置切换顶点组等默认键位。

> 首次安装插件以后必须点击注册内置资源库才能使用 hotools 内置的大量资源，包含材质节点组、几何节点组、后处理节点组、材质
> 默认插件不开启 exicon 、omninode，自己按需打开

# 功能入口

Hotools 的设计理念是尽量贴合原版的设计风格
所有的数据操作功能都尽量放在对应数据属性面板下
所有的在 3dviewport 中的快捷操作都放在右键面板中

> 需要注意的是，属性-数据面板下的 Hotools 面板可能会被其他插件挤占导致无法显示 
> 所有的属性-数据面板都设计为左侧为功能区折叠开关，右侧为视图显示/整体控制开关
> 尤其注意由于 blender 的各种属性数据都不支持多个物体的同步列表切换，因此每个区域都有一个多物体同步模式，可以将选中的物体的这些列表属性同步（尽力同步，并且只有在改变时才会刷新）

![[Pasted image 20260729163353.png]]

| 入口                  | 主要内容               |
| ------------------- | ------------------ |
| 3D 视图 `N > HoTools` | 形态键、骨骼、动画、检查等主要面板  |
| 右键 (多模式不同)          | 物体、建模、骨骼、UV 等快捷操作  |
| 属性-数据               | 每个数据类型下都有开关面板      |
| 属性-物体               | HoTools 物理与碰撞属性    |
| 属性-骨骼               | Hotools 辅助骨        |
| 插件偏好设置              | 可选模块、内置资产与快捷键      |
| Omninode节点图         | OmniNode 自动化和物理节点图 |
