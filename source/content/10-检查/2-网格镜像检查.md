# 网格镜像检查

![[../_assets/screenshots/checker/Pasted image 20251213040408.png]]
![[../_assets/screenshots/checker/Pasted image 20251213040409.png]]

这个模块专门处理本来应该对称、后来因为雕刻或局部编辑变得不对称的网格。对于镜像修改器生成的模型，以及雕刻时忘记打开对称的情况通常最有效。

==它不是稳定的通用重拓扑工具。复杂模型可能匹配错误，执行前一定保留副本。==

## 自动修复

选择镜像轴后执行“自动修复对称”。默认优先使用较稳定的镜像 UV 检查，也可以组合拓扑和重叠 UV 规则寻找顶点对。

- 检查拓扑：适合左右拓扑仍然严格对应的模型。
- 检查镜像 UV：适合 UV 本身左右镜像的模型。
- 检查重叠 UV：适合两侧 UV 重叠，或应用镜像时没有镜像 UV 的情况。

容差应从小值开始增加，越大越容易把不相关顶点误配。不要为了让所有点都匹配而一次把容差调得很大。

## 手动修复

自动结果仍有少量顽固点时，可以分别获取两个活动顶点索引，交换当前镜像点对，或指定一侧后执行“点强制对称”。

手动修复适合收尾，不适合逐点修完整个不对称模型；大量失败通常说明镜像轴、物体变换或 UV 条件本身不对。
