# 检查预览

检查预览是 3D 视图标题栏中的弹出面板。它直接绘制当前可见网格，适合边改边看；和 [[1-物体检查|物体检查]] 的结果列表是两套独立功能。

## 显示方式

打开显示后选择检查模式。拓扑、UV 或物体发生变化时点击“刷新检查预览”；开启“实时刷新”会自动重建，但大模型下会明显增加交互开销。

所有模式都能调整不透明度。UV 栅格还可以选择 UV Grid、Color Grid、Checker 或自定义图片，并按 `512-8192` 的像素密度预览。

## UV 检查

- UV 栅格：直接观察拉伸、方向和纹素密度。
- UV 岛：显示每个岛内部归一化后的 `UV`、`U` 或 `V`。
- UV 象限：第一象限为绿色，其他象限使用固定随机色。
- UV 拉伸：绿色接近当前中位密度，蓝色表示 UV 相对偏大，红色表示相对偏小。
- UV 面积畸变：绿色接近岛内面积比例，红色表示局部面积变化较大。
- UV 手性：白色正常、黑色镜像、灰色未定义。

## 网格与物体检查

- Ngon：五边及以上的面标红。
- 空间四边形：对角线空间间距超过阈值时标红。
- 正反面：正面绿色、反面红色。
- 物体缩放：缩放为 1 显示绿色，非 1 显示蓝色，负缩放显示红色。

> 预览读取的是当前可见对象。隐藏对象不会替你做离线检查，正式交付前仍建议再跑一次物体检查列表。
