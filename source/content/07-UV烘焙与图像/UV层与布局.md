# UV 层与布局

## UV 从层替换

把指定来源 UV 层的数据写入目标层。说明对象范围、活动层、点/Loop 对应和覆盖行为。

## 移动活动 UV 层

调整活动 UV 层在列表中的顺序，适合满足导出端对第一 UV 的约定。

## 选中 UV 适配到第一象限

整体缩放和平移所选 UV，使其进入 0-1 区域。记录是否保持比例、边距和多岛布局。

## UV 转形态键

把 UV 坐标映射为网格形态，便于检查或特殊烘焙。说明坐标轴、缩放和新键命名。
