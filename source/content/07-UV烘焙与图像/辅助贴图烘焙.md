# 辅助贴图烘焙

## 基础输出

- UV 岛填充图、网格孤岛填充图、岛 UV 图。
- UV 面 ID、物体 ID、材质 ID。
- 顶点色贴图、顶点组权重贴图。

## 方向与场输出

- World Space TB FlowMap。
- Gravity FieldMap。
- UV 手性图。
- 切线/副切线图。

## 光照与距离输出

- 六向可见度 Lightmap。
- 光源 Cast Lightmap。
- 岛 SDF 图。

## 每项统一补写

说明输入对象/UV、输出分辨率、边距、颜色含义、文件格式、保存路径、耗时和典型用途。“快速导出”单独说明它组合了哪些输出。
