# 图像选区与蒙版

## 选区画布

创建默认选区画布，或使用当前图像尺寸；刷新画布并清空选区。说明画布是临时数据还是 Blender Image。

## 从选中 UV 填充遮罩

把 UV 编辑器中的选择栅格化为像素遮罩，记录分辨率、边界和抗锯齿。

## 扩展与收缩蒙版

按像素半径扩张或腐蚀遮罩。

## 变换遮罩像素

对遮罩内容进行平移、缩放或其他变换。补写坐标基准、插值和越界处理。

## 编辑图像选区

说明交互工具的启动、确认、取消和叠加/替换模式。
