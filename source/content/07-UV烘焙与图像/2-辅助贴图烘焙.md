使用时先选中需要参与输出的网格，并确认它们的活动 UV 层。多数输出都支持设置宽高、背景透明度和边缘膨胀；膨胀会让颜色越过 UV 边界几像素，用来避免采样时出现接缝。

## 分区与 ID 图

- UV 岛填充图：每个 UV 岛使用独立纯色。
- 网格孤岛填充图：按几何连通块区分颜色。
- UV 面 ID：相邻面使用不同颜色。
- 物体 ID：每个选中物体使用不同颜色。
- 材质 ID：按面使用的材质区分颜色。

这组图最适合在 PS、Substance 3D Painter 等软件中快速建立选区。它们是制作辅助数据，不应直接当成最终材质颜色使用。

## UV 与方向图

- 岛 UV 图：每个岛单独归一化，`R=U`、`G=V`。
- World Space TB FlowMap：把世界轴投影到每个 UV 岛的切线空间。
- Gravity FieldMap：记录重力方向在切线/副切线平面内的方向与强度。
- UV 手性图：白色为正常、黑色为镜像、灰色为未定义。
- 切线/副切线图：输出 Blender 计算的 MikkTSpace 方向。

方向图对法线、切线和镜像 UV 很敏感。结果不对时先检查物体变换、活动 UV 与自定义法线，不要只靠换颜色空间碰运气。

## 光照与距离图

- 六向可见度 Lightmap：从世界 `+/-X、+/-Y、+/-Z` 六个方向检测遮挡。
- 光源 Cast Lightmap：使用指定 Light 对象进行直接光照检测。
- 岛 SDF 图：记录 UV 岛内部到边缘的距离，越白表示离边缘越远。

这类输出需要更多计算，分辨率和模型数量会直接影响耗时。

## 活动顶点色/顶点组

活动顶点色或活动顶点组权重直接烘焙到 UV 图像。顶点组输出是灰度权重，适合在外部软件检查或继续加工。
