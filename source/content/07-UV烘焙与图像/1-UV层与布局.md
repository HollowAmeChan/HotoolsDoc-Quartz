## 移动活动 UV 层

调整活动 UV 层在列表中的位置。
移动只改变层顺序，不会把层内坐标复制到其他层。
> 少数特殊格式只能导出最上的层，与 bl 内部的语义不同，需要考虑这个问题
## UV 从层替换

类似形态键的局部替换，把另一个 UV 层的数据写到当前层，只影响编辑模式中选中的网格。

> 最常见的用途是修复合并物体后的 UV：两个物体原来的活动层名称不同，例如一个叫 `UVMap`、另一个叫 `UV贴图`，合并后正确数据被拆到了两个层里。先切到需要保留的目标层，再从另一层替换缺失部分即可。

## 选中 UV 适配到第一象限

![[Pasted image 20260730213609.png|375]]
把所选 UV 整体等比缩放并平移到 `0-1` 第一象限，岛之间的相对布局保持不变。
适合处理整组 UV 整体跑出第一象限的情况；它不是重新展开，也不会自动解决岛重叠。

## UV 转形态键

把当前 UV 坐标转换成一个形态键，让网格在 3D 视图中展开成 UV 布局。
> 主要用于布料与拓补，以及特殊的数据传递
