# 图像选区与蒙版

这套工具使用 HoTools 自己维护的固定分辨率硬选区，主要用于在 Blender 内快速处理贴图局部，不会替代完整的图像编辑软件。

## 建立选区画布

“默认选区画布”会设为 `2048 x 2048`；“使用当前图像尺寸”会读取图像编辑器中的活动图像。画布尺寸应该和正在处理的图一致，否则选区边界会错位。

修改尺寸后使用“刷新选区画布”重采样当前选区；如果不再需要，使用“清空选区”。

## 编辑图像选区

“编辑图像选区”支持框选或画笔编辑硬选区。它记录的是选中/未选中，不会产生羽化灰度。

从选中 UV 填充遮罩时，会把 UV 编辑器当前选中的面栅格化到选区：

- 直接执行：替换当前选区。
- `Shift`：叠加到当前选区。
- `Ctrl`：从当前选区减去。

## 拓展与收缩

每次拓展会向外增加 1 像素，每次收缩会向内减少 1 像素。适合给 UV 边缘留出安全范围，或去掉容易采到相邻区域的边界。

## 变换遮罩像素

该功能会扣出选区覆盖的像素，进入移动、缩放和旋转交互，按 `Enter` 应用。操作前最好另存原图；连续变换会发生重复插值，不适合来回缩放。
