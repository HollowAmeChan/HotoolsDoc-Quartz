
# 顶点色绘制与预设

![[Pasted image 20260729214017.png]]

本工具比较简单，看面板就看得懂怎么使用
需要注意的是，顶点色一般是 `面拐-字节颜色` 这样才能有硬边
填充画笔 icon 的是使用本行的颜色，黑白方块是快速 01，R 是随机颜色，加号可以快速添加一个手工预设
也可以使用自带的预设

一般用于快速制作 IDmask、各种硬边黑白遮罩
最好配合 UV 工具里面的快速导出活动顶点色使用

通道合并功能极少使用，如果你需要制作合并通道的 mask，可以在外部软件合并通道（ps/sd）
如果真的需要合并通道的顶点色可以尝试使用这个功能


# 顶点色转换与选择

## 按顶点组赋预设色

按顶点是否属于各组来分配预设颜色，不以具体权重为主要依据。

## 按顶点组赋随机色

为不同顶点组生成随机颜色，适合快速检查分区。记录重叠组的优先级。

## 选择相同顶点色面

以活动颜色为样本，按容差选择颜色接近的面。补写时记录采样域和颜色空间。

## 权重转顶点色

把活动顶点组权重转换为黑白顶点色，用于可视化或贴图烘焙。

## 烘焙自定义法线到顶点色

![[Pasted image 20260730144841.png]]

把已有自定义法线编码到颜色属性，可用于 lilToon 等读取顶点色的描边方向与厚度修正流程。实时修改器预览不一定等同于网格中已经写入的自定义法线。
此功能需要手动测试
Liltoon 支持 rgb 修朝向，a 修厚度，因此最好使用第三种模式
