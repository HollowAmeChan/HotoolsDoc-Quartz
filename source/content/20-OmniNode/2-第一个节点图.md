# 第一个 OmniNode 节点图

## 最小示例

1. 新建一棵 OmniNodeTree。
2. 给节点树添加一个 Float 输出接口，并放置“组输出”节点。
3. 添加两个“浮点数”和一个“Float 加法”节点。
4. 把两个浮点数接到加法，再把结果接到组输出。
5. 点击“编译运行”。

需要观察中间值时，把“Debug 打印”插在加法和组输出之间。它会把输入值输出到 Blender 控制台，并原样传给下游；标题输入可以区分多个 Debug 节点。

> Debug 打印本身不是输出终点。它仍然需要连接到组输出或其他输出节点，否则整条分支不会被编译。

## Socket

未连接的输入使用节点面板中的默认值，连接后由上游输出提供。Socket 类型必须兼容，不能连接时到 [[节点参考/数据与转换|数据与转换节点]] 中插入明确的类型转换。

不要把 Any Socket 当成所有类型都可以随意混用。它只是让部分通用节点接收运行时值，下游仍应知道自己真正需要的类型。

## 输出节点决定执行范围

OmniNode 从所有 `is_output_node` 节点反向收集依赖。没有通向任何输出终点的节点不会执行，即使仍然显示在画布上。

这条规则也适用于有副作用的节点：创建数据、写入属性、Debug 打印或物理解算如果没有进入输出分支，都可能完全不运行。

## 执行顺序

可达节点按数据依赖拓扑排序。节点在画布上放得更左或更右不会改变顺序；需要明确先后时，用输入输出连接建立依赖。

Frame 和 Reroute 只负责整理画布，不参与业务计算。
