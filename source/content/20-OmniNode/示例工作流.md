# OmniNode 示例工作流

示例只使用最少节点，每个示例都应提供完整图、关键参数和最终结果。

## 计划示例

- [ ] 数值、类型转换与 Debug 打印。
- [ ] 从集合读取对象并批量写入变换。
- [ ] 批量创建或整理 UV 层。
- [ ] 拆分图片通道、调整后重新合并并保存。
- [ ] 用组引用封装可复用处理。
- [ ] 用组批量处理对象列表。
- [ ] 用 Runtime Cache 制作软跟随，并显式清理缓存。
- [ ] 创建最小物理世界并提交一帧。
- [ ] MC2 简单布料、SpringBone VRM 和 Jolt 刚体各一个最小图。
- [ ] 烘焙模拟结果并清除 Bake 动画。

## 截图命名

使用 `omninode-example-<topic>-graph.png` 和 `omninode-example-<topic>-result.png` 成对保存。
