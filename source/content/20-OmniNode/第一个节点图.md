# 第一个 OmniNode 节点图

## 最小示例

建议使用“浮点数 -> Float 加法 -> Debug 打印”作为第一个图。将最终节点标记为输出节点或接到具有输出语义的节点，执行后在控制台或调试区域检查结果。实际按钮名称需要在 Blender 中补图确认。

## 输入 Socket

未连接的输入使用节点上的默认值；连接后由上游节点提供值。Socket 类型不兼容时需要插入 [[节点参考/数据与转换|类型转换节点]]。

## 输出节点决定执行范围

OmniNode 从 `is_output_node` 为真的节点反向收集依赖。没有连接到任何输出节点的分支不会执行，即使节点仍显示在画布上。一个图可以有多个输出终点。

## 执行顺序

可达节点按依赖进行拓扑排序。不要依靠节点在画布中的左右位置推断先后；需要顺序时用数据依赖或高层封装节点明确表达。

## Blender 原生编辑节点

Frame 和 Reroute 用于整理画布，不是普通 OmniNode 业务节点。
