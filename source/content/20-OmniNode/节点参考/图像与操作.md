# 图像与通用操作节点

## 图像

- 导入图片、批量导入图片、保存图片。
- 设置图像颜色。
- 纹理 UV 重定向。
- 合成图片、合成图片（外部）。
- 拆分/合并图片通道。
- 调整法线贴图强度。

图像节点会直接创建或修改 Blender Image 数据。批处理前统一检查色彩空间、Alpha、分辨率和保存路径；合成输入尺寸不一致时不要默认它会自动得到想要的缩放结果。每帧图中反复导入、保存或调用外部合成会产生明显 IO 开销。

## 变换与属性

- 写入物体变换、写入增量变换、变换合成。
- 采样浮点曲线、采样颜色曲线、按曲线设置位置。
- 设置 Datablock 数据。

## 集合、路径与字符串

- 创建集合、获取集合中的物体。
- 文件路径识别（正则）。
- 字符串连接。
- 创建 UV 层（通用操作入口，注意与 UV 分类节点的关系）。

## Debug 打印

输入值会以类型和 `repr` 形式打印到 Blender 控制台，并原样输出。标题为空时使用默认前缀；每帧运行时应尽快关闭 Debug 分支，否则控制台输出量会很大。
