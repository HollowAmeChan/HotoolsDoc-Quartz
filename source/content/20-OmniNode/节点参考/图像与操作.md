# 图像与通用操作节点

## 图像

- 导入图片、批量导入图片、保存图片。
- 设置图像颜色。
- 纹理 UV 重定向。
- 合成图片、合成图片（外部）。
- 拆分/合并图片通道。
- 调整法线贴图强度。

每项补写色彩空间、Alpha、分辨率不一致、路径、覆盖、内存和外部进程依赖。

## 变换与属性

- 写入物体变换、写入增量变换、变换合成。
- 采样浮点曲线、采样颜色曲线、按曲线设置位置。
- 设置 Datablock 数据。

## 集合、路径与字符串

- 创建集合、获取集合中的物体。
- 文件路径识别（正则）。
- 字符串连接。
- 创建 UV 层（通用操作入口，注意与 UV 分类节点的关系）。

## Debug 打印

打印输入值用于定位图中数据。补写输出位置、复杂 Blender 数据的显示方式和每帧运行时的日志量风险。
