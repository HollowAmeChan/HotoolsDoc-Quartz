# 传统物理节点

此页对应添加菜单中的 `Physics` 分类，不等同于新的 [[../物理世界/index|物理世界]]。新工程优先使用物理世界的 MC2、SpringBone VRM 或 Jolt 流程；传统节点主要用于兼容已有节点图和单节点测试。

## 网格物理 XPBD

Python 后端的网格物理解算节点。它会跨帧保存解算状态，并在每帧读取输入网格、固定点、可见碰撞体、对象变换、场景帧率和步长。拓扑或播放连续性变化后应清运行缓存重建。

## 网格物理 XPBD CPP

使用 native C++ 后端加速的同类节点。说明与 Python 版的参数对应、兼容平台、回退行为和结果差异。

## 骨骼姿态 K 帧

把节点计算出的骨骼姿态写成关键帧。它会修改动画数据，正式使用前先复制 Action；已有同帧同通道关键帧可能被更新，不适合把原动画当成无损输入反复烘焙。
