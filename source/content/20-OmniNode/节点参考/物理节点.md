# 传统物理节点

此页对应添加菜单中的 `Physics` 分类，不等同于新的 [[../物理世界/index|物理世界]] 分类。补写时需要确认哪些节点仍推荐用于新工程。

## 网格物理 XPBD

Python 后端的网格物理解算节点。记录输入网格、固定点、碰撞、步长、迭代、缓存和写回。

## 网格物理 XPBD CPP

使用 native C++ 后端加速的同类节点。说明与 Python 版的参数对应、兼容平台、回退行为和结果差异。

## 骨骼姿态 K 帧

把节点计算的姿态写成关键帧。记录帧范围、骨骼范围、覆盖已有动画和插值。
