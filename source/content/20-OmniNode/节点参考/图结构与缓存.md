# 图结构与缓存节点

## 图结构

- 组输入：暴露当前子树的输入接口。
- 组输出：暴露输出接口，并作为子树执行终点。
- 组引用：调用另一个 OmniNode 树。
- 组批量：为列表中的每项调用子树。
- 输出/结构类节点：按当前 Add 菜单补齐实际名称和行为。

## Runtime Cache

- Cache Read：按 key 读取已提交值，并定义未命中默认值。
- Cache Write：写入或透传值。
- Cache Delete：删除 key 或当前命名空间。
- Cache Dump：输出用于调试的快照。

## 状态型函数节点

- 软跟随：从零变换开始追向目标物体，使用 Cache Read/Write 保存位置、旋转和速度。跳帧或帧不连续时会重置状态；响应、超调和最大速度控制跟随质感。
- 漂浮：根据波形与噪波生成位置、旋转和缩放偏移。频率控制变化速度，种子只影响噪波；输出可以先与软跟随做变换合成，再写入控制器。
