# 图结构与缓存节点

## 图结构

- 组输入：暴露当前子树的输入接口。
- 组输出：暴露输出接口，并作为子树执行终点。
- 组引用：调用另一个 OmniNode 树。
- 组批量：为列表中的每项调用子树。
- 输出/结构类节点：按当前 Add 菜单补齐实际名称和行为。

## Runtime Cache

- Cache Read：按 key 读取已提交值，并定义未命中默认值。
- Cache Write：写入或透传值。
- Cache Delete：删除 key 或当前命名空间。
- Cache Dump：输出用于调试的快照。

## 状态型函数节点

- 软跟随：使用跨帧状态生成滞后跟随结果。补写位置/旋转输入、阻尼、初始化和重置。
- 漂浮：生成随时间变化的漂浮状态。补写振幅、频率、随机种子、缓存 key 和清理方式。
