# 动画工具

入口为 `N > HoTools > 动画工具`。

## Action 处理

### 应用活动物体动画到所选物体

以活动对象为来源，把动画复制或应用到其他所选对象。补写 Action 是共享还是复制、动画槽和对象类型要求。

### 批量清除动画槽

清理所选对象的动画槽。说明 Action 数据块是否保留，以及 NLA 是否受影响。

### 修复缩放导致的动画位移错误

针对缩放后的骨架或对象修正 Action 中的位移曲线。执行前备份 Action，并记录缩放应用状态和支持的通道。

## 刚体辅助

### 设置视图

切换到适合观察刚体的视图显示状态。

### 分类碰撞体

按碰撞组组合为刚体分配视图颜色，便于检查过滤设置。

### 复制刚体约束到所选

以活动约束为来源，把设置复制到其他所选约束。

### 生成刚体约束

根据选择与参数批量创建刚体约束。说明对象配对、约束类型、命名、集合和重复生成。
