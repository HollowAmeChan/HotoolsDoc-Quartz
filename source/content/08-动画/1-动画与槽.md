
# 动画与槽

## 应用活动物体动画到选中物体

以活动物体为来源，把它当前的 Action 和 Action 槽应用到其他选中物体。默认还会同步 Action 混合方式、外推、影响值和 NLA 开关。

适合多个结构相同的对象共用一份动画。执行前必须让来源物体最后成为活动物体；目标物体只需要保持选中。

> 这是共用同一个 Action，不是复制一份独立 Action。之后编辑这份动画会同时影响所有引用它的物体。

## 批量清除动画槽

清除选中物体当前 Action 的槽绑定，但不会删除 Action 数据。主要用于 Blender 4.4 之后重新分配 Action 槽，或者解决复制对象后槽仍然指向旧对象的问题。

清除后需要手动重新选择正确的槽，否则物体可能保留 Action 但不再有有效曲线绑定。

## 修复缩放导致的动画位移错误

当骨架物体带有等比缩放时，骨骼 `location` 动画在应用缩放后会出现位移幅度错误。该功能会把所有 Action 中 `pose.bones[].location` 的关键帧和手柄乘以骨架缩放，再应用骨架物体的 Scale。

==这是破坏性操作，必须先备份文件。==

- 会处理当前文件中的全部 Action，不只处理当前骨架正在使用的动画。
- 只支持等比缩放；非等比缩放会停止执行。
- 骨架原点应位于世界中心。
- 修复后的 Action 只适用于新尺寸，不能再给原尺寸骨架使用。
- IK 和其他 Rig 控制器的位置可能需要重新装配。

如果文件里混有其他角色或不属于这个骨架的 Action，先拆到单独文件再处理。
